{% load i18n %} {% comment %} One confirmation dialog for every page, in place of the browser's native one. - Markup: data-confirm="Remove this area?" on a
, or on the submit button that needs it. Optional: data-confirm-label="Remove" for the confirm button, data-confirm-safe on actions that aren't destructive (a primary button instead of a red one). - JavaScript: `if (!(await window.confirmDialog(message, {label, safe}))) return;` Escape or Cancel close it and resolve to false; focus returns to the element that opened it. Opening it focuses its first button, Cancel, so Enter never confirms by mistake. {% endcomment %}
